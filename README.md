# think outside the box · demo

Versión de demostración del reto diario de redes y ciberseguridad.
Es independiente de la web oficial (thinkoutsidethebox.es): no guarda estadísticas y permite jugar cualquier reto.

## Cómo usarla
Abajo a la izquierda (arriba en el móvil) está la barra **DEMO**:

- **Formato**: Aleatorio o uno concreto — Texto, Tipo test, Encuentra la línea, Ordenar, Completar, Rack, Planta, Terminal.
- **Reto**: elige un reto concreto (R001–R300) o uno al azar del formato.
- **↻**: siguiente reto.

Cada carga empieza de cero. Arriba se muestra el identificador del reto para poder comentar uno concreto.

## Contenido
- 300 retos: 90 de texto y 30 de cada formato visual.
- Una sola página HTML, sin servidor ni dependencias.

## Publicarla en GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
